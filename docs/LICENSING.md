# Licensing status

No blanket license selected for FLYZRDS yet. The web foundation and harness are newly authored; this does not relabel upstream code or data.

The candidate upstream `eonsystemspbc/fly-brain` snapshot declares GNU GPL version 2 in its root LICENSE. Its model remains in a separately fetched ignored checkout. Our benchmark invokes its public functions rather than copying model implementation into FLYZRDS. Pinning and attribution do not remove license obligations. Before distributing a combined simulator or serving a production product, assess applicable code obligations and record a concrete distribution decision.

The processed FAFB data came from that public repository. Its code license is not assumed to license the underlying dataset. Exact upstream preprocessing provenance and dataset redistribution terms still need verification against FlyWire release documentation. Do not redistribute tables or checkpoints while unresolved. Direct Codex interactive exports require sign-in; this task did not sign in or bypass access controls.

Frontend packages retain their own licenses in npm dependencies/lockfile. No third-party artwork/audio/fonts are included. Browser sensors are not enabled. This is an engineering provenance record, not a legal opinion.
